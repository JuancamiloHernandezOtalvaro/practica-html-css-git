# Práctica HTML, CSS y Git

Repositorio creado para practicar y aprender conceptos básicos de **HTML, CSS y Git/GitHub** durante mi formación en desarrollo de software.

## 📂 Contenido

* `index.html` — Página principal de prueba.
* `formulario.html` — Práctica de creación de formularios.
* `prueba.html` — Página utilizada para realizar diferentes pruebas con HTML.
* `style.css` — Estilos CSS utilizados en las páginas.

## 🎯 Objetivo

Practicar la creación y modificación de páginas web utilizando HTML y CSS, mientras aprendo a utilizar Git y GitHub para guardar y organizar mis proyectos y cambios.

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3
* Git
* GitHub
